# AI 시대의 조직 지식·전문성·암묵지 교육자료 기초조사 프롬프트

당신은 **조직행동론, 지식경영, 인적자원관리, 생성형 AI, LLM, 전문가 연구(Expertise Studies)**를 종합적으로 연구하는 리서처이자 기업교육 컨설턴트다.

나는 기업 임직원을 대상으로 다음 주제의 교육자료를 만들고자 한다.

> **“개인의 역량을 어떻게 조직과 시스템의 역량으로 전환할 것인가 — AI 시대의 전문성, 암묵지, 조직지식과 인간의 역할”**

단순한 AI 기술 소개가 아니라,
**기업이 사람의 지식과 경험을 어떻게 조직 자산으로 전환해야 하는지**, 그리고 **LLM의 등장으로 일반지식·전문지식·암묵지·창의성의 가치가 어떻게 달라지는지**를 논리적으로 설명하는 것이 교육의 목적이다.

아래 질문을 중심으로 충분한 기초자료를 검색하고, 교육자료 제작에 활용할 수 있는 **리서치 베이스 문서**를 작성하라.

## 1. 핵심 연구 질문

다음 질문을 각각 독립적으로 검토하되, 마지막에는 하나의 논리적 흐름으로 연결하라.

### A. 인원과 전문성의 관계

* “원숭이가 몇 마리면 사람 한 명을 대체할 수 있는가?”라는 사고실험을 조직 생산성 관점에서 어떻게 해석할 수 있는가?
* 단순 노동이나 병렬화 가능한 업무에서는 인원 증가가 전문성을 어느 정도 대체할 수 있는가?
* 반대로 인원을 늘리는 것으로 해결할 수 없는 업무는 어떤 특성을 갖는가?
* 업무 분해 가능성, 병렬화 가능성, 조정 비용, 오류 검증 비용, 문제 정의 난이도 등의 관점에서 설명하라.
* Brooks's Law, coordination cost, division of labor, collective intelligence 등 관련 개념이 있다면 연결하라.

### B. “대리 여러 명이 부장 한 명을 대체할 수 있는가?”

직급 자체가 아니라 **숙련도와 전문성의 차이**라는 관점에서 분석하라.

특히 다음을 조사하라.

* 숙련자는 초보자보다 단순히 지식을 많이 가지고 있는 것인가?
* 숙련자는 문제를 바라보는 방식 자체가 다른가?
* 패턴 인식, chunking, mental model, recognition-primed decision making, expert intuition, problem representation 등의 연구를 찾아라.
* 전문가의 가치가 “더 많은 일을 하는 것”보다 “불필요한 탐색 공간을 줄이는 것”에 있다는 주장을 뒷받침할 근거가 있는지 검토하라.
* 전문성이 의사결정 속도와 판단 품질에 어떤 영향을 미치는지 조사하라.

### C. 경험 많은 직원의 암묵지는 어떻게 조직으로 가져올 수 있는가?

Tacit Knowledge와 Explicit Knowledge에 관한 주요 이론을 조사하라.

반드시 다음 개념을 포함하라.

* Michael Polanyi의 Tacit Knowledge
* “We know more than we can tell”의 의미
* Nonaka & Takeuchi의 Knowledge Creation / SECI Model
* Socialization, Externalization, Combination, Internalization
* Knowledge Management
* Communities of Practice
* Apprenticeship / Mentoring
* After Action Review
* Decision Log
* Case-based Learning

그리고 다음 문제를 비판적으로 검토하라.

> “숙련자의 지식을 인터뷰해서 문서로 만들면 조직 지식이 되는가?”

암묵지 중 무엇이 문서화될 수 있고, 무엇은 경험·관찰·실습을 통해서만 전수되기 쉬운지 구분하라.

### D. 암묵지는 조직에서 제거해야 할 비효율인가?

다음 두 개념을 명확히 구분하여 설명하라.

1. 암묵지가 존재하는 것
2. 중요한 암묵지가 특정 개인에게만 독점되어 있는 것

기업 관점에서 각각 어떤 장점과 위험이 있는지 분석하라.

특히 다음 질문에 답하라.

* 모든 업무를 매뉴얼화하는 것이 이상적인 조직인가?
* 표준화와 전문성은 충돌하는가?
* 예외 상황과 불확실성이 많은 업무에서는 암묵지가 왜 필요한가?
* 개인 의존성(Key-person risk)을 줄이면서도 전문성을 유지하는 방법은 무엇인가?

### E. LLM의 “확률적으로 높은 답”과 일반지식은 같은 것인가?

LLM의 작동 원리를 기술적으로 과도하게 복잡하지 않게 설명하되, 개념적으로는 정확하게 정리하라.

다음을 구분하라.

* Next-token prediction
* Token probability
* 언어적 개연성
* 사실적 진실성
* 학습 데이터의 분포
* Common knowledge / conventional wisdom
* Hallucination

특히 다음 명제를 검토하라.

> “LLM은 확률적으로 가장 높은 답을 하기 때문에 결국 가장 일반적인 지식을 출력하는 기계다.”

이 문장에서 맞는 부분과 틀린 부분을 구분하라.

“높은 생성 확률 ≠ 높은 진실 확률”이라는 명제를 교육생이 쉽게 이해할 수 있는 사례도 제시하라.

### F. 일반지식과 전문지식 중 무엇이 더 가치 있는가?

단순히 “전문지식이 더 가치 있다”고 결론 내리지 말고 다음 관점에서 분석하라.

* Scarcity
* Decision impact
* Context specificity
* Transferability
* Reliability
* Cost of acquisition
* Half-life of knowledge

그리고 기업에서 다음 세 종류의 지식을 구분할 수 있는지 검토하라.

1. 누구나 접근 가능한 일반지식
2. 특정 분야의 전문지식
3. 특정 기업·고객·조직에만 존재하는 맥락적 지식

LLM이 일반지식의 접근 비용을 크게 낮춘다면, 상대적으로 어떤 지식의 가치가 높아질 것인지 논증하라.

### G. LLM은 일반지식을 조합하여 창의적인 결과를 만들 수 있는가?

창의성을 “완전히 새로운 것을 무에서 창조하는 능력”으로만 정의하지 말고 다음 연구 관점에서 검토하라.

* Combinatorial Creativity
* Conceptual Blending
* Divergent Thinking
* Convergent Thinking
* Novelty
* Usefulness
* Idea Diversity

생성형 AI가 사람의 창의성을 높인다는 연구와, 반대로 결과의 다양성을 낮추거나 평균으로 수렴시킬 수 있다는 연구를 함께 조사하라.

특히 다음 가설을 검토하라.

> “AI는 개인의 평균적인 창의성은 높일 수 있지만, 집단 전체의 아이디어 다양성은 낮출 수도 있다.”

근거가 있다면 연구 결과와 함께 설명하라.

## 2. 최종적으로 도출해야 할 핵심 질문

앞의 내용을 종합하여 다음 질문에 답하라.

> **AI 시대에 기업이 관리해야 할 것은 사람의 수인가, 지식의 양인가, 아니면 조직의 학습 능력인가?**

그리고 다음 관점을 중심으로 결론을 도출하라.

### 기존 조직관리

Human
→ Knowledge
→ Documentation
→ System

### AI 시대에 검토할 조직관리

Human Experience
→ Judgment / Knowledge
→ Organizational System
→ AI Retrieval / Synthesis
→ Human Decision
→ New Experience
→ Updated Organizational Knowledge

즉,

> **개인의 지식을 시스템으로 빼내는 일방향 구조가 아니라, 사람과 시스템이 서로를 계속 학습시키는 Knowledge Loop가 필요한 것은 아닌가?**

이 주장을 이론과 사례를 통해 검토하라.

## 3. 자료 조사 원칙

검색 자료는 신뢰도를 구분하여 사용하라.

우선순위는 다음과 같다.

1. 원 논문 / 학술지 / 학회 자료
2. 대학·연구기관 자료
3. 정부·국제기구 보고서
4. 신뢰할 만한 컨설팅·산업 보고서
5. 기업의 공식 기술자료
6. 언론 기사
7. 블로그·개인 의견

가능한 경우 블로그의 2차 해석보다 **원 연구를 직접 찾아라.**

고전 이론과 최신 AI 연구를 구분하라.

특히 생성형 AI와 LLM 관련 연구는 가능한 한 **최근 연구와 최신 리뷰 논문**을 우선적으로 확인하라.

모든 중요한 주장에는 출처를 연결하라.

자료 간 의견이 충돌한다면 어느 한쪽을 임의로 선택하지 말고,

* 무엇에 대해서 합의가 있는지
* 무엇이 아직 논쟁적인지
* 연구 조건에 따라 결과가 어떻게 달라지는지

를 구분하여 작성하라.

## 4. 결과물 구성

최종 결과는 아래 구조로 작성하라.

### ① Executive Summary

전체 내용을 1~2페이지 수준으로 요약하라.

반드시 다음 질문에 대한 잠정적인 결론을 포함하라.

* 사람이 많아지면 전문성을 대체할 수 있는가?
* 전문가는 무엇이 다른가?
* 암묵지는 없애야 하는가?
* LLM은 평균적인 지식을 생성하는 기계인가?
* AI 시대에는 어떤 지식이 희소해지는가?
* AI는 창의성을 높이는가 낮추는가?
* 기업의 조직관리는 어떤 방향으로 변해야 하는가?

### ② 핵심 개념 사전

다음 개념을 교육생이 이해할 수 있도록 각각 3~5문장으로 설명하라.

* Tacit Knowledge
* Explicit Knowledge
* SECI Model
* Expertise
* Expert Intuition
* Recognition-Primed Decision
* Knowledge Management
* Organizational Learning
* Collective Intelligence
* Coordination Cost
* Next-token Prediction
* Hallucination
* General Knowledge
* Contextual Knowledge
* Combinatorial Creativity
* Divergent / Convergent Thinking

### ③ 연구 질문별 조사 결과

앞서 제시한 A~G 질문별로 다음 형식으로 정리하라.

**핵심 주장**

**근거가 되는 이론**

**대표 연구**

**반론 또는 한계**

**기업 실무에서의 의미**

**교육자료에서 사용할 수 있는 사례**

### ④ 교육에 사용할 수 있는 인상적인 연구·사례

최소 10개를 찾아라.

각 사례마다 다음을 적어라.

* 사례명
* 어떤 현상을 보여주는가
* 핵심 결과
* 교육에서 어떻게 사용할 수 있는가
* 출처

가능하면 숫자나 실험 결과가 명확한 연구를 우선하라.

### ⑤ 활용 가능한 비유와 사고실험

다음 소재를 교육적으로 발전시켜라.

* Infinite Monkey Theorem
* “대리 10명 vs 부장 1명”
* 매뉴얼만 읽은 요리사
* 내비게이션을 가진 초보 운전자 vs 길을 아는 택시기사
* 평균적인 답을 내는 AI
* 100명이 같은 ChatGPT를 사용했을 때 아이디어가 비슷해지는 현상

각 비유에 대해

**무엇을 설명하기 좋은가 / 어디까지 유효한가 / 어떤 오해를 만들 수 있는가**

를 구분해서 작성하라.

### ⑥ 조직관리 관점의 Framework 제안

조사 결과를 바탕으로 기업의 지식을 다음과 같이 분류하는 Framework를 하나 이상 제안하라.

예:

| 구분       | AI/시스템으로 이전 | 인간이 보유 | 공동 관리 |
| -------- | ----------- | ------ | ----- |
| 반복 업무    |             |        |       |
| 명시지      |             |        |       |
| 일반지식     |             |        |       |
| 기업 특화 지식 |             |        |       |
| 예외 판단    |             |        |       |
| 암묵지      |             |        |       |
| 창의적 탐색   |             |        |       |

단순 분류를 넘어 각 영역에서

* 시스템화해야 하는 것
* AI가 지원해야 하는 것
* 사람이 직접 책임져야 하는 것

을 제안하라.

### ⑦ 최종 메시지 후보

강의 전체를 관통할 수 있는 메시지를 최소 10개 제안하라.

예를 들어 다음과 같은 방향을 발전시켜도 좋다.

* “AI는 전문가를 없애는 것이 아니라 평균적인 지식의 가격을 떨어뜨린다.”
* “앞으로 희소한 것은 답이 아니라 맥락이다.”
* “조직의 경쟁력은 얼마나 많이 아는가보다 얼마나 빨리 배우는가에서 나온다.”
* “사람을 시스템으로 바꾸지 말고, 사람과 시스템이 서로를 학습시키게 하라.”
* “전문가의 가치는 더 많이 아는 것이 아니라 무엇을 보지 않아도 되는지 아는 데 있다.”

각 문장은 강의 제목이나 슬라이드 헤드라인으로 사용할 수 있을 정도로 짧게 작성하라.

## 5. 출처 정리

마지막에 **Annotated Bibliography**를 작성하라.

각 자료마다 다음 정보를 포함하라.

* 저자
* 연도
* 제목
* 발행처 / 학술지
* URL 또는 DOI
* 핵심 주장 2~3문장
* 이번 교육자료에서 활용할 수 있는 포인트
* 출처 신뢰도: 높음 / 중간 / 참고용

최소 20개의 핵심 자료를 선정하라.

단순히 많은 자료를 나열하지 말고, 실제 교육자료 제작에 활용 가치가 높은 자료를 우선순위화하라.

## 6. 작성 원칙

문체는 학술 논문처럼 지나치게 어렵게 쓰지 말고 **기업 임직원 교육자료를 만드는 사람이 읽기 좋은 수준**으로 작성하라.

중요한 개념은 가능한 한

**이론 → 쉬운 설명 → 기업 사례 → AI 시대의 의미**

순서로 풀어라.

사실, 연구 결과, 해석, 추론을 명확히 구분하라.

흥미로운 주장이라도 근거가 부족하다면 단정하지 말고 “가설”, “해석”, “논쟁 중인 주장”이라고 표시하라.

최종 결과물의 목적은 완성된 강의안을 만드는 것이 아니다.

**후속 단계에서 PPT와 강의 스토리라인을 설계할 수 있도록, 신뢰도 높은 근거와 개념을 충분히 확보한 ‘기초 연구 문서’를 만드는 것**이 목적이다.
